Privacy policy

Colab Drive Fallback is a personal-use desktop OAuth configuration for rclone. Effective date: 8 November 2026.

Google data accessed and purpose

With the account owner's permission, the client accesses Google Drive file metadata and file contents to list or locate the owner's intended research files, read datasets, and create or update outputs and checkpoints. Its read/write permission can also allow deletion of files when explicitly requested by the owner. It does not request Google Photos, Gmail or Contacts access.

Where data and credentials are stored

Files remain in Google Drive unless the owner chooses to download, cache or process them on a local computer or an explicitly approved compute environment. OAuth credentials are stored in protected client configuration on the owner's computer. Placing credentials or data in a remote runtime is a separate owner-controlled decision; anyone controlling that runtime may be able to access them.

Temporary filesystem cache can contain file contents or pending uploads. It is controlled by the computer or runtime on which the client operates. Losing that runtime can destroy unsent cache; it does not remove files whose upload to Drive has already completed.

Sharing and use

The configuration has no separate operator-hosted data-processing or storage backend. It does not sell Google user data, use it for advertising, or provide it to unrelated third parties. Transfers occur between Google Drive and the owner-authorized client or compute environment. Google and the selected compute or hosting providers process their services under their own terms and privacy policies. This configuration's use of Google API data is limited to the file-access functionality described here and follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation and deletion

The owner controls retention of files in Drive, downloaded data and local cache. Access can be revoked through Google Account third-party connections. The owner can also stop mounts and remove the local rclone configuration, credentials and cache. Revoking access or deleting client configuration does not itself delete research files already stored in Drive; deleting those files is a separate owner action.

This information website

This static website contains no login form, OAuth callback, application analytics script, or file-upload feature. It does not receive Drive credentials or file contents. Its hosting provider, GitHub Pages, may process ordinary website request information under GitHub's privacy statement.

Contact and changes

Questions can be sent through the project's issue tracker. Public issues must not include credentials, personal account identifiers or private files. Changes to this policy will be published on this page with an updated effective date.
