Colab Drive Fallback

A personal-use desktop OAuth configuration for accessing the account owner's Google Drive with rclone.

Purpose

This configuration supports an authorized personal research workflow. Native Google Colab Drive mounting is preferred. An independently authorized rclone filesystem mount can be used as a fallback when the native flow requires owner-device verification that is not currently available.

It is not a public storage service, a sign-in service, or a file relay. This website provides information only. It does not perform authentication, receive OAuth callbacks, accept uploads, or access Drive files.

Requested access

The desktop client requests Google Drive read and write access so that the owner can read datasets and create or update research outputs and checkpoints. That Google permission can also permit file deletion; the owner should only run trusted code and authorize operations they intend.

Files are transferred directly between Google Drive and the local client or an explicitly approved compute environment. A mounted folder can use temporary local cache; a file is not a durable backup until its upload has completed.

Personal use

This configuration is intended for the account owner's own use. It is not an invitation for other people to authorize their accounts. It is independently operated and is not an official Google or rclone service.

Privacy and support

Read the privacy policy for information about access, storage, revocation and deletion. For questions about this configuration, contact its maintainer through the project's issue tracker. Do not include credentials, private filenames or file contents in public issues.
